# MediaMaster: A Comprehensive Offline Tool for Microbiological Media Preparation

![Cover](cover.png)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20172515.svg)](https://doi.org/10.5281/zenodo.20172515)

MediaMaster is a free, open-source, serverless, single-page HTML5 application designed for microbiologists, biotechnologists, and researchers. It integrates a vast database of microbiological culture media with real-time scaling calculators, simplifying the preparation process without requiring an internet connection.

## Key Features

- **Extensive Media Database**: Includes exact formulations for PDA, PDB, LB, Czapek Dox, MacConkey, and many more.
- **Real-Time Scaling Calculator**: Automatically calculates required component weights based on the desired target volume.
- **Cost Calculation Engine**: Estimates the cost of preparation per batch.
- **Offline Functionality**: Entirely browser-based with no backend server; your data and recipes remain on your local device.
- **Modern User Interface**: A responsive, academic-grade design built for laboratory settings.

## Getting Started

1. Download the `index.html` file.
2. Double-click the file to open it in any modern web browser (Chrome, Firefox, Edge, Safari).
3. No installation, dependencies, or internet connection are required.
